Distributed CI / Go / self-hosted

ForgeCI is a distributed CI engine built from scratch in Go.

It parses repository-local DAGs, persists orchestration in PostgreSQL, leases work to remote runners, transports immutable source, and reports results back to GitHub.

DAG scheduling · remote execution · durable leases · immutable source · artifacts and cache · GitHub-native SCM

Correctness ledger / 03

Claims have repository evidence.

The ledger points to executable tests, mutation checks, and integration harnesses—not a feature list standing in for proof.

P-01

Exact revision execution

If an event references commit A and its branch advances to B, ForgeCI still executes A.

Mechanism

Exact SHA fetch, detached checkout, SHA verification, immutable snapshot.

EvidenceMaterialization testsMutation D/E
P-02

Fenced work ownership

A stale runner cannot complete work after lease ownership has moved.

Mechanism

PostgreSQL lease identity, expiry, and runner-matched renewal and completion.

EvidenceRunner lease contractLease ownership tests
P-03

One delivery → at most one run

Retrying the same accepted delivery does not create another pipeline run.

Mechanism

Run, snapshot association, jobs, dependencies, and SCM trigger persist in one transaction.

EvidenceTransactional trigger storeMutation I
P-04

Cross-runner artifacts

A downstream job restores declared output without relying on a shared mutable workspace.

Mechanism

Durable content-addressed artifact storage with explicit publication and restoration.

EvidenceSelf-hosting harnessArtifact tests
P-05

Durable external status

A lost create response or restart does not orphan the desired GitHub Check state.

Mechanism

Persistent desired state and bounded reconciliation using a deterministic external ID.

Design boundaries / 07

Deliberate non-goals.

  • Kubernetes runner scheduling
  • Autoscaling
  • GPU scheduling
  • Runner labels / selectors
  • Automatic reassignment after runner loss
  • General pipeline secrets
  • RBAC / multi-tenancy
  • Highly available control plane
